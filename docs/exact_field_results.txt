=== Exact finite-field sweep (𝔽_p · GF(2^8) · GF(2)) ===

Front door: field::fit_fp(f, p, &degrees) / fit_gf256(f, &degrees).
Compression in BYTES: the packed 𝔽_p model hoists the prime ONCE (in the
model context) and stores bare u64 values — no per-coefficient prime.

── 1b. 𝔽_p in-reach maps: packed compression by lever, BYTES (p = 257) ──

 id  name                            degree    denseB   hoistB  sparseB  pooledB   save
  1  field product a*b                [1,1]       128       64       96       80    38%
  4  cube x^3                           [3]       128       64      112      104    19%
  5  S-box 7*x^3 + 3                    [3]       128       64      128      120     6%
  6  mix a*b + a + b                  [1,1]       128       64      128      112    12%

  denseB→hoistB = the prime-hoist (each Fp 16 B → bare u64 8 B, prime stored once)
  hoistB→sparseB = dropping exact zeros (the SPARSE footprint)
  sparseB→pooledB = interning repeated values. The per-coefficient prime
  repetition is gone; holds for large Mersenne/Fermat primes too (u64 payload).

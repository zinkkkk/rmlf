=== Exact ℚ sweep: fit_poly / fit_rational, byte-level compression ===

Front door: rational::fit_poly(f, &degrees) / fit_rational(f, &num, &den).
Compression is in BYTES — the packed form pools repeated BigRationals and
the canonical rescale clears shared denominators (eval-invariant).

  denseB  = dense coefficient bytes (2·∏k entries as full BigRationals)
  sparseB = after dropping exact zeros (the SPARSE footprint: nonzero values + index)
  pooledB = after also interning repeated values (distinct values once + u32 codes)
  canon%  = bit saving from the joint primitive-integer rescale (eval-invariant)

  The two byte levers are sparsity (denseB→sparseB) and value pooling
  (sparseB→pooledB); the canonical rescale then shrinks each value's bits.
  Cases 0–9 recover EXACTLY; 10 is a deliberate under-resolved limit;
  11/12 are pole / non-coprime edges that still recover off the singular set.
